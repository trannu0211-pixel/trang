# Lớp Học Mặc Đẹp

Một website học tập thời trang bằng tiếng Việt, thiết kế responsive và chạy trực tiếp trên trình duyệt.

## Tính năng
- Khám phá lớp học theo chủ đề, tìm kiếm theo tên và mô tả.
- Xem thông tin chi tiết lớp học và bắt đầu học.
- Lưu lớp học yêu thích bằng `localStorage`.
- Khu vực theo dõi tiến độ, đăng ký nhận cảm hứng qua email và thông báo tương tác.
- Bố cục tối ưu cho máy tính, máy tính bảng và điện thoại.

## Chạy thử
Mở `index.html` trong trình duyệt. Google Fonts và ảnh minh họa cần kết nối internet.
